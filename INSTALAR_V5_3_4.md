# Instalar V5.3.4

1. Exporta el respaldo JSON desde la aplicación, sin borrar el historial.
2. Desde `~/Descargas/Domicili0s-V3`, actualiza la rama `main`, verifica un árbol limpio y crea una rama de respaldo.
3. Instala el ZIP completo en la raíz del repositorio.
4. Ejecuta `node --check` para todos los archivos frontend y `node tests/*.js` individualmente.
5. Publica en GitHub `AnFeCaMo/Domicili0s`, rama `main`; Render despliega si el servicio mantiene auto deploy.
6. Confirma `/api/health` con versión `5.3.4`.
7. En el teléfono, prueba primero detenido: ubicación actual, dirección de destino, longitud vial, advertencias de desvío y voz.

No modifiques manualmente las reglas para compensar una geocodificación incorrecta. Verifica primero que el destino sea el correcto.
